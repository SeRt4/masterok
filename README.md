## 🎯 Основные возможности

| Модуль | Описание |
|--------|----------|
| 👤 **Авторизация** | Регистрация и вход с хешированием паролей |
| 🛒 **Каталог** | 120+ товаров в 12 категориях с фильтрацией |
| 🛍️ **Корзина** | Добавление, удаление, изменение количества |
| 📧 **Email-уведомления** | Автоматическая отправка чеков на почту |
| 📦 **Заказы** | История заказов в личном кабинете |
| 📊 **Статистика** | Подсчёт потраченной суммы |
| 👨‍💼 **Профиль** | Редактирование данных и смена пароля |
| 🗺️ **Карта складов** | Визуализация расположения складов |
| 📱 **Адаптивность** | Работает на всех устройствах |

## 🚀 Технологии

### Backend
- **PHP 8.2+** — серверная логика
- **JSON** — хранение данных (users.json, orders.json)
- **SMTP** — отправка писем через Яндекс.Почту

### Frontend
- **HTML5 / CSS3** — структура и стили
- **JavaScript (ES6+)** — интерактивность
- **LocalStorage** — хранение корзины
